# Проект по курсу "Фронтэнд и бекэнд разработка"
## О проекте
Этот репозиторий содержит работу по разработке проекта по дисциплине "Фронтэнд и бекэнд разработка"  

**Тема:** Веб-сайт небольшой сети фитнес центров, включающий несколько страничных страниц и механизмы автоматизированного взаимодействия и клиентами

## Используемые технологии
- HTML 5
- CSS
- JS
## Используемые фреймворки и ассеты
- Bootstrap 5
